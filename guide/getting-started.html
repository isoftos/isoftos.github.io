快速开始

安装

项目已经初始化完成，依赖已安装。

开发

启动本地开发服务器：

npm run dev

VuePress 会在 http://localhost:8080 启动一个热重载的开发服务器。

编写内容

创建新页面

在 docs 目录下创建新的 Markdown 文件即可创建新页面。例如：

# 创建一个新的博客文章
echo "# 我的第一篇博客" > docs/my-first-post.md

Markdown 增强

VuePress 支持标准的 Markdown 语法，还有一些增强功能：

代码块

// 支持语法高亮
export default {
  name: 'MyComponent',
  mounted() {
    console.log('Hello VuePress!')
  }
}

配置导航和侧边栏

编辑 docs/.vuepress/config.js 文件来配置导航栏和侧边栏。

构建

构建生产版本：

npm run build

构建后的文件会输出到 docs/.vuepress/dist 目录。

部署

你可以将构建后的静态文件部署到任何静态网站托管服务，如：

  • GitHub Pages
  • Netlify
  • Vercel
  • 阿里云 OSS
  • 腾讯云 COS
