指南

欢迎来到 OmniStackHub！

这是什么？

这是一个基于 VuePress 构建的知识库和博客系统。你可以使用 Markdown 来编写文档和博客文章。

特性

  • 📝 Markdown 支持 - 使用 Markdown 编写内容
  • 🎨 主题定制 - 可自定义的主题系统
  • 🔍 搜索功能 - 内置搜索功能
  • 📱 响应式设计 - 完美支持移动设备
  • ⚡️ 快速构建 - 基于 Vite 的快速构建

目录结构

OmniStackHub/
├── docs/
│   ├── .vuepress/
│   │   └── config.js      # VuePress 配置文件
│   ├── guide/             # 指南目录
│   │   ├── README.md
│   │   └── getting-started.md
│   └── README.md          # 首页
├── package.json
└── node_modules/
